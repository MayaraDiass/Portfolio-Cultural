## 🚀 Como Publicar no GitHub Pages

### Passo 1: Criar um repositório no GitHub
1. Acesse [github.com](https://github.com)
2. Clique em **"New"** (criar novo repositório)
3. Nome do repositório: `mayarad1as.github.io` (importante! use seu username)
4. Descrição: "Portfólio de Gestão Cultural e Produção"
5. Marque como **Public**
6. Clique em **"Create repository"**

### Passo 2: Fazer upload dos arquivos
**Opção A - Via Web (Mais fácil):**
1. Abra o repositório criado
2. Clique em **"Add file"** → **"Upload files"**
3. Arraste os arquivos `index.html` para o navegador
4. Clique em **"Commit changes"**

**Opção B - Via Git (Terminal):**
```bash
# Clone o repositório
git clone https://github.com/seu-usuario/seu-usuario.github.io.git
cd seu-usuario.github.io

# Copie os arquivos aqui
cp index.html .

# Faça o commit
git add index.html
git commit -m "Adiciona portfólio profissional"
git push -u origin main
```

### Passo 3: Ativar GitHub Pages
1. Vá para **Settings** do repositório
2. Desça até **Pages**
3. Em **Branch**, selecione `main`
4. Clique em **Save**
5. Aguarde alguns minutos e seu site estará online em: `https://seu-usuario.github.io`
